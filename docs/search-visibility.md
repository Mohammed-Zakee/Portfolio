# Search visibility

Primary portfolio: https://mohammed-zakee.github.io/Portfolio/

The portfolio uses both confirmed names, SLIIT and fintech in descriptive metadata, a canonical URL, ProfilePage/Person structured data, and links to LinkedIn, GitHub, Instagram and Linktree. It deliberately avoids hidden keyword text and unsupported ranking claims. The sitemap includes the homepage and both case studies. Existing Google verification tags/files are preserved.

## Account steps

1. Open Google Search Console with the account that owns the existing verification. Select or add the URL-prefix property `https://mohammed-zakee.github.io/Portfolio/`.
2. Submit `https://mohammed-zakee.github.io/Portfolio/sitemap.xml` in Sitemaps. Inspect the homepage URL, test the live URL and request indexing. Inspect each case study too. Check the reports later for actual indexing and search queries; submitting does not guarantee indexing or rankings.
3. On LinkedIn, keep the public profile visible, add the portfolio to Contact info and Featured, and use a factual headline such as “AI Undergraduate at SLIIT | Fintech & Strategic Partnerships”. Mention “Mohammed Zakee, also known as Zakee Nowfal” naturally in About.
4. On GitHub, add the portfolio to the profile website field and use a consistent public name. A profile README can introduce both names and link to the portfolio and strongest project case study.
5. On Linktree, make the portfolio the first link with the title “Zakee Nowfal — AI & Fintech Portfolio”. Use consistent names in its public profile.
6. On Instagram, link to the portfolio in the bio if desired. Its public visibility is your choice; private content cannot be made discoverable through portfolio metadata.

External account changes and Search Console submissions have not been performed by this repository update. They require authenticated access. Do not publish private certificate originals for search visibility.

## Hosting details

This is a GitHub Pages project under `/Portfolio/`. Its `robots.txt` is not the host-root `/robots.txt`, so submit the sitemap directly in Search Console. Browser tab icons work on project pages; Google Search chooses one favicon per hostname, so the search-result icon may require the same favicon on the root `mohammed-zakee.github.io` site (or a custom domain). Do not create another duplicate site just for keywords.
