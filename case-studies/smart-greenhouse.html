01 / THE PROBLEM

What needed solving?

A growing environment needs monitoring and timely responses to changing conditions. The project explores how multiple sensor inputs can inform automated control rather than relying only on manual checks.

02 / IMPLEMENTATION

How the system fits together.

As a team, we developed a Smart Greenhouse IoT system using an ESP32, DHT22, LDR, soil-moisture and ultrasonic sensors, with automated control of a water pump, fan, and lighting system.

03 / ENGINEERING CHOICES

The choices and their trade-offs.

One controller, multiple inputs

An ESP32 brings the sensor and actuator sides into one system. The important engineering challenge is making the combined behavior dependable, rather than treating each sensor as an isolated demo.

A mix of sensing methods

The project combines temperature/humidity, light, soil moisture, and ultrasonic sensing. This spans different physical measurements and the integration work needed to use them together.

Control that affects the physical world

A pump, fan, and lights make this more than a passive dashboard. Calibration, safe actuator behavior, and handling faulty readings are important next validation steps.
